Murem removes the background music from videos and audio and keeps the voices and dialogue, using AI vocal separation. It can now do this on your phone, with no server.

Processing modes:
• Internal (on-device): the separation model runs on the phone with ONNX Runtime. No server and no Termux needed
• Local (Termux): run the Murem server in Termux on the same phone, with one-tap Install / Start / Stop
• Server: connect to your own server on a PC for faster GPU processing (Docker supported, found on the local network with mDNS)

Input:
• Links from YouTube, Instagram, TikTok, Vimeo and other sites supported by yt-dlp
• Several links at once: paste, add, or import a .txt file
• Local video and audio files (MP4, MKV, WebM, MP3, M4A and more)
• Share from any app to start; the right mode opens automatically
• Built-in yt-dlp, updated from Settings when links stop working

Models:
• On-device: MDX-NET HQ3, MDX-NET Voc FT, a small 30 MB model for low-end phones (MDX-NET 3_9662), UVR KARA 2 for the lead vocal only, and Kim Vocal 2 (optional, with a license notice)
• Models download on first use and can be deleted to free space
• Server and Termux: Kim Vocal 2, MDX-NET HQ3, Karaoke, Mel-Band RoFormer, BS-RoFormer, or any custom audio-separator model

Output:
• MP4 with the original video, or audio only as MP3 or M4A
• Bitrate 128k / 192k / 320k
• Performance settings for on-device jobs: threads, quality or speed, batch size, and a time estimate while processing

Sites that need a login:
• Log in inside Murem with the built-in browser, or import a cookies.txt file
• Cookies are kept per site, can be switched on or off per site, and are excluded from backups

Player:
• Built-in player with an audio waveform: tap to play or pause, drag to seek
• Rewind / forward 10 s, loop, volume, fullscreen with landscape rotation
• Open in an external player (VLC, MX Player and others)

History:
• Recent results show where each one was made: On device, Termux or Server
• Search, long-press for video details, save and share results, export all at once
• Processing queue that survives app restarts

Design:
• Redesigned Home screen with one input card for links and files
• Settings split into clear sections
• Two-pane layouts on tablets and other large screens
• Light, Dark, Black (OLED) and System themes
• Material You colors on Android 12+, or one of 8 color palettes
• Home screen widget with 4 themes
• 16 languages

Privacy:
• In Internal mode, processing stays on your device. Files are not uploaded anywhere
• Login cookies are stored only on the device and are only sent to the sites you switch on
• In Server or Termux mode, files go only to the server you run yourself
• Network access is used to download links, models (from GitHub and Hugging Face) and yt-dlp updates

Murem is open source (MIT). On-device processing is slow on most phones and uses a lot of battery, so keep the phone charging for long videos.
